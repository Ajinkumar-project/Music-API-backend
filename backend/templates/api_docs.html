YTMusic API Documentation

Django REST Framework API for YouTube Music data via ytmusicapi and yt-dlp

API Endpoints

GET /api/home/
Fetch the YouTube Music home page data including featured playlists, new releases, and recommended content.

Response Example:

{
  "results": [
    {
      "title": "India's biggest hits",
      "contents": [...]
    }
  ]
}
GET /api/playlist/{playlist_id}/
Fetch a playlist by its ID. Returns playlist details including title, description, thumbnail, and all tracks with video_id and high-quality thumbnails.

Path Parameters:

playlist_id YouTube Music playlist ID (e.g., RDCLAK5uy_krbBs7P2iEb30IODyVbiOXWyhZtAIX9Uk)

Response Example:

{
  "id": "RDCLAK5uy_krbBs7P2iEb30IODyVbiOXWyhZtAIX9Uk",
  "title": "Uncut Bollywood",
  "description": "Enjoy stripped down versions...",
  "thumbnail": "https://yt3.googleusercontent.com/...",
  "tracks": [
    {
      "id": "GX9x62kFsVU",
      "title": "Gehra Hua",
      "video_id": "GX9x62kFsVU",
      "artists": [{"name": "Arijit Singh", "id": "UCDxKh1gFWeYsqePvgVzmPoQ"}],
      "duration": "3:51",
      "thumbnail": "https://i.ytimg.com/vi/GX9x62kFsVU/maxresdefault.jpg"
    }
  ]
}
GET /api/album/{album_id}/
Fetch an album by its browse ID. Returns album details including title, year, artists, and all tracks with video_id and high-quality thumbnails.

Path Parameters:

album_id YouTube Music album browse ID (e.g., MPREb_e9PRbX2AzDi)

Response Example:

{
  "title": "Bass Test Subwoofer (Car Bass Test Extreme)",
  "year": "2022",
  "thumbnail": "https://yt3.googleusercontent.com/...",
  "artists": [{"name": "Bass Test", "id": "UCowKeSiz5uaIG2XZiL-8E-w"}],
  "tracks": [
    {
      "id": "NOYL3Onxx_8",
      "title": "10 Hz Shifting 15 Hz Frequency Deep Bass",
      "video_id": "NOYL3Onxx_8",
      "artists": [{"name": "Bass Test", "id": "UCowKeSiz5uaIG2XZiL-8E-w"}],
      "duration": "0:45",
      "thumbnail": "https://i.ytimg.com/vi/NOYL3Onxx_8/maxresdefault.jpg"
    }
  ]
}
GET /api/artist/{artist_id}/
Fetch an artist by their channel ID. Returns artist details including name, subscribers, description, thumbnails, songs, albums, singles, videos, and related artists.

Path Parameters:

artist_id YouTube Music artist channel ID (e.g., UCptBkLZ6XRxoyn8SkUMc_Iw)

Response Example:

{
  "channel_id": "UCLH5ojAg1XIyxcOCazK4n-Q",
  "name": "Alka Yagnik",
  "subscribers": "2.19M",
  "thumbnails": [...],
  "description": "Alka Yagnik is an Indian playback singer...",
  "views": "1,874,742,360 views",
  "songs": {"browseId": "VLOLAK5uy_...", "results": [...]},
  "albums": {"browseId": "MPADUCptBkLZ6XRxoyn8SkUMc_Iw", "results": [...]},
  "singles": {...},
  "videos": {...},
  "related": [...]
}
GET /api/genre/
Fetch all available music genres and moods from YouTube Music. Returns categories like "Moods & moments" and "Genres".

Response Example:

{
  "results": {
    "Moods & moments": [
      {"title": "Chill", "params": "ggMPOg1uX1JOQWZFeDByc2Jm"},
      {"title": "Commute", "params": "ggMPOg1uX044Z2o5WERLckpU"}
    ],
    "Genres": [
      {"title": "Pop", "params": "ggMPOg1uX1lLQkxHbHhWQUUy"},
      {"title": "Rock", "params": "ggMPOg1uXzJKTm5jUEZ5Uzlu"}
    ]
  }
}
GET /api/genre/{genre_name}/
Fetch playlists for a specific genre or mood. Uses the genre name to find matching playlists from YouTube Music.

Path Parameters:

genre_name Genre or mood name (e.g., Pop, Rock, Chill, Party)

Response Example:

{
  "results": [
    {
      "title": "Happy Pop Hits",
      "playlistId": "RDCLAK5uy_mfdqvCAl8wodlx2P2_Ai2gNkiRDAufkkI",
      "thumbnails": [...],
      "description": "Playlist • YouTube Music"
    }
  ]
}
GET /api/pop/
Fetch YouTube Music charts/popular data including top music videos, top artists, and trending content globally or by country.

Response Example:

{
  "results": {
    "countries": {"selected": {"text": "Global"}, "options": ["IN", "US", "GB", ...]},
    "videos": [
      {
        "title": "Daily Top Music Videos - Global",
        "playlistId": "PL4fGSI1pDJn6t3TXLGiiJdD-sZbrG3tG0",
        "thumbnails": [...]
      }
    ],
    "artists": [
      {
        "title": "Alka Yagnik",
        "browseId": "UCptBkLZ6XRxoyn8SkUMc_Iw",
        "subscribers": "2.19M",
        "thumbnails": [...],
        "rank": "1",
        "trend": "neutral"
      }
    ]
  }
}
GET /api/search/?q={query}
Search for songs on YouTube Music. Returns matching songs with video_id, artists, album, and thumbnail information.

Query Parameters:

q Search query string (e.g., "test", "bollywood", "rock")

Response Example:

{
  "results": [
    {
      "title": "Bujwa Test",
      "resultType": "song",
      "videoId": "720a3bhOIvM",
      "category": "Songs",
      "artists": [{"name": "Magwe ZA", "id": "UCayIBGwL5RGNZvlrrrXkHhQ"}],
      "album": {"name": "Bujwa Test", "id": "MPREb_62jleG8sLq6"}
    }
  ]
}
GET /api/stream/{video_id}/
Get the direct audio stream URL for a YouTube video using yt-dlp. Returns the best audio quality stream URL along with metadata.

Path Parameters:

video_id YouTube video ID (e.g., KHxrQgFBKeQ)

Response Example:

{
  "url": "https://rr4---sn-25ge7nzr.googlevideo.com/videoplayback?...",
  "title": "Kaan Check Sound Check",
  "duration": 180,
  "thumbnail": "https://i.ytimg.com/vi/KHxrQgFBKeQ/maxresdefault.jpg",
  "ext": "mp4"
}
